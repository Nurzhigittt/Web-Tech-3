- Mobile: each box occupies 12 columns.
- Tablet: each box occupies 6 columns.
- Desktop: each box occupies 4 columns.

## Part 3. Combined Project

### Task 4. Responsive Portfolio Page

I combined Bootstrap Grid and custom media queries.

The page includes:
- A shared Bootstrap navbar at the top.
- Project cards on the left and a personal information sidebar
  on the right on desktop.
- Stacked sections on smaller screens.
- A footer across the bottom.

Custom media queries change font sizes and padding.
Additional personal information is hidden on mobile screens.
